## 2026-11-05 다른 사람 구름 + 검수
- 요청: "다른사람이 그린 그림도 랜덤 하게 뜨면 좋겠는데, 어드민 사이트 두고 내가먼저 검수하고 승인한 그림들만"
- 서버·로그인: Cloudflare만(D1 + Pages Functions + Access). 후보 Supabase는 무료 프로젝트 수 제한과 별도 로그인 구현 때문에 뺐다. 내 추천을 사용자가 고름.
- 공유 동의: 보낼 때 체크박스(기본 켬). 자동 제출은 그린 사람이 모르게 공개될 수 있어 뺐다. 내 추천을 사용자가 고름.
- 보여주기: 닉네임도 같이. 내 추천(익명)이 아니라 사용자가 고름. 그래서 닉네임은 선택·10자 이내로 하고 검수 때 같이 본다(사용자가 추천안 고름).
- 어드민: 승인·거절, 승인 그림 내리기, 새 그림 알림, 간단 통계 모두.
- 알림: 메일. 계정에 있던 개인 도메인으로 Email Routing을 쓰려 했다. 아무 주소로 보내는 Email Service는 Workers 유료 플랜이라, 무료인 '인증한 내 주소로 보내기'를 쓴다. 하루 한 번 요약.
- 도배 막기: 횟수 제한만(Turnstile은 뺌, 사용자가 추천안 고름).

## 2026-11-05 알림 메일 빼기
- 결정: 새 그림 알림을 뺀다. 어드민 통계의 대기 개수로 확인.
- 누가: 사용자(다른 용도로 쓰는 도메인은 건드리지 않기로 함 → 알림 방법 질문에 '알림은 빼기').

- 버린 시도: 개인 도메인 Email Routing + 매일 09:00 notify Worker. 코드까지 만들었으나 도메인을 건드리지 않기로 해서 지움.

## 2026-11-05 배포와 어드민 잠금
- Zero Trust는 이미 켜져 있었다. 계정에 있던 다른 Access 앱은 건드리지 않고 새 앱을 만들었다.
- 대상: `sky-doodle.pages.dev/admin`과 미리보기 배포용 `*.sky-doodle.pages.dev/admin`. 정책은 '운영자 메일만 허용'.
- 서버에는 팀 도메인과 AUD를 환경값으로 넣어 Functions가 토큰을 다시 검증한다. IP 해시 소금은 무작위 값을 비밀값으로 넣었다(저장소에 없음).
