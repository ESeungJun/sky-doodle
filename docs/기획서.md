# 하늘 스케치북 기획서

## 목표
스케치북에 그린 그림이 뭉게구름이 되어 하늘에 떠오르는 작은 놀이 사이트. 여기에 **다른 사람이 그린 구름도 내 하늘에 랜덤하게 흘러가게** 해서, 혼자 그려도 누군가와 같은 하늘을 보는 느낌을 준다. 다른 사람에게 보이는 그림은 운영자가 먼저 검수해 승인한 것만.

## 사용자
- 방문자: 그림을 그려 하늘로 보낸다. 원하면 다른 사람 하늘에도 띄운다.
- 운영자(1명): 어드민에서 들어온 그림을 검수한다.

## 기능
### 필수
1. 그림 → 구름 변신 → 하늘로 떠오름 (기존)
2. 내 구름은 브라우저에 저장 (기존)
3. 보낼 때 '다른 사람 하늘에도 띄우기' 체크박스(기본 켬) + 닉네임(선택, 10자 이내, 비우면 '익명', 브라우저가 기억)
4. 승인된 다른 사람 구름 3~5개가 닉네임과 함께 조금 멀리·작게 흘러가고, 화면을 벗어나면 다른 구름으로 바뀐다. 공유 구름은 스케치북 뒤 아래쪽에서 두둥실 떠올라 등장한다
   - 화면을 열어 둔 동안 새로 승인된 구름은 새로고침 없이 30초 안에 떠오른다(꽉 차 있으면 가장 오래된 공유 구름이 스르르 사라짐)
5. 어드민 `/admin`
   - 대기 목록을 구름 모양 미리보기로 보고 승인·거절(하나씩, 여러 개 한꺼번에)
   - 승인한 그림 내리기
   - 간단 통계: 오늘 제출, 대기, 승인, 거절
6. 도배 막기: 같은 접속에서 1시간 5개·하루 20개, 대기 500개 넘으면 잠시 받지 않음

### 나중
- 승인된 구름에 '좋아요' 같은 반응
- 운영자 여러 명
- 새 그림 알림(메일·메신저). 도메인을 쓰지 않기로 해서 지금은 어드민의 대기 개수로 확인

## 범위 밖
- 회원 가입, 내가 공유한 그림 목록 보기, 공유 취소(운영자에게 요청)
- 이미지 업로드(선 데이터만 받는다)

## 완료 기준
- 체크해서 보낸 그림이 어드민 대기 목록에 뜨고, 승인하면 다른 브라우저 하늘에 닉네임과 함께 떠오른다
- 거절·내린 그림은 어디에도 안 보인다
- 어드민은 운영자 메일 인증 없이는 페이지도 API도 열리지 않는다
